EJECT — WolfJam 2026 planning pack

Files:
- AGENTS.md : permanent shared constraints for implementation and review agents
- PLAN.md   : game design, implementation stages, test gates and deadline rules
- PROMPTS.md: one-at-a-time builder prompts and reusable read-only reviewer prompt

Setup:
1. Create a new repo for the project and copy AGENTS.md + PLAN.md into repo root.
2. Keep PROMPTS.md locally, or in docs/ if desired.
3. Start implementation with Stage 1 prompt only.
4. After each stage, manually playtest and run a read-only review.
5. Confirm hackathon theme/registration and submit well before deadline.

The pack is documentation only, not game code.
